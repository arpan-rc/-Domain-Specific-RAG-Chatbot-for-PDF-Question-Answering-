# -Domain-Specific-RAG-Chatbot-for-PDF-Question-Answering-
Domain-Specific RAG Chatbot is a document-grounded AI system built with Streamlit, LangChain, FAISS, and Groq. It parses PDF files, creates semantic vector embeddings, and retrieves relevant context to generate precise answers. It includes source page citations, hallucination guardrails, user feedback.
